# 🐍 Python Practice Lab

A growing collection of Python practice projects covering conditionals, calculations, and loop-based logic — built while strengthening core programming fundamentals.

This repository serves as an ongoing lab for experimenting with different Python concepts through small, real-world style programs.

---

## 📂 Projects List

| # | Project | Description |
|---|---------|-------------|
| 1 | **Student Result Management** (`student_result_management.py`) | Takes marks for 5 subjects, calculates total & percentage, and assigns a grade. |
| 2 | **Currency Converter** (`currency_converter.py`) | Converts amount between PKR and USD based on a fixed exchange rate. |
| 3 | **Salary Calculator** (`salary_calculator.py`) | Calculates gross salary, tax amount, and net salary from basic salary and bonus. |
| 4 | **Car Parking Fee Calculator** (`car_parking_fee_calculator.py`) | Calculates parking fee based on the number of hours parked. |
| 5 | **Mobile Package Selector** (`mobile_package_selector.py`) | Lets the user choose between Daily, Weekly, or Monthly mobile packages and shows the price. |
| 6 | **Food Ordering System** (`food_ordering_system.py`) | A menu-driven ordering system using a `while` loop — lets the user order multiple items and prints a final bill. |

---

## 🚀 How to Run

1. Clone this repository:
```bash
   git clone https://github.com/abdulrehman-nasrullah/python-practice-lab.git
```
2. Navigate into the project folder:
```bash
   cd python-practice-lab
```
3. Run any project file using Python:
```bash
   python food_ordering_system.py
```
